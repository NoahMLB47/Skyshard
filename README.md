# Description

This is a game based on the arcade/Sega Mega Drive game Zero Wing. I was given a template by my lecturer which included the mini engine and some basic features like spawning the player, enemies, basic enemy AI and shooting. The rest was done myself.

The best parts I did myself were: [Boss.cpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/Boss.cpp), [Boss.hpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/Boss.hpp), [NPCManager.cpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/NPCManager.cpp), [NPCManager.hpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/NPCManager.hpp), [TextBox.cpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/TextBox.cpp), [TextBox.hpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/TextBox.hpp), [UI.cpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/UI.cpp), [UI.hpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/UI.hpp), [TextureManager.cpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/TextureManager.cpp), [TextureManager.hpp](https://github.com/NoahMLB47/Skyshard/blob/main/Windows-VS2022/SDL2_Project/TextureManager.hpp)
